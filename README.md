# 🏋️ BMI Calculator  

A simple and responsive **BMI (Body Mass Index) Calculator** that helps users determine their BMI based on weight and height.  

## 🚀 Features  
✅ Calculate BMI quickly based on height and weight  
✅ Responsive UI for desktop & mobile  
✅ Categorizes BMI results (Underweight, Normal, Overweight, Obese)  
✅ Clean and minimal design  

## 🛠 Tech Stack  
- **Frontend**: HTML, CSS, JavaScript
